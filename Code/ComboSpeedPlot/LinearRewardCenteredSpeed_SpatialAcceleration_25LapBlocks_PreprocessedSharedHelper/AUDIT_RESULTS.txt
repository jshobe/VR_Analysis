Regression design
-----------------
test_single_reward_preprocessing.m constructs a clean kinematic sequence and
an event-expanded copy containing duplicate reward/lick rows. It verifies:
  - event rows are preserved;
  - the kinematic sequence is identical to the clean sequence;
  - speed values at genuine position rows are unchanged;
  - redundant rows receive NaN speed;
  - row accounting and stored audits pass.

run_single_reward_preprocessing_audit.m additionally verifies on a real file:
  - forced rebuilding succeeds;
  - the exact saved MAT file reopens successfully;
  - source SHA-256 is preserved;
  - the second load accepts the fresh cache without rebuilding;
  - shared speed mapping passes.
